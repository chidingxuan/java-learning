# 任务卡：客户管理控制台（D1 实战）

目标：用 Java 写出一个能用、能改、能调试的控制台小程序，为 D2 换乘 JDBC 打底。

## 要求

1. 两个文件：`Customer.java`、`App.java`（`App` 里放 `main`）。
2. `Customer` 类：字段 `int id`、`String name`、`String phone`、`int level`；带全参构造方法；重写 `toString()` 让打印可读。
3. `App` 里用 `List<Customer> customers = new ArrayList<>()` 存放数据，实现四个方法：
   - `add`：新增一个客户
   - `findById`：按 id 查找，找不到返回 `null`
   - `updatePhone`：按 id 改电话
   - `remove`：按 id 删除
4. 在 `main` 里把四个方法各调用一次，用 `System.out.println` 打印每步前后结果，让人一眼看出数据变化。
5. 故意制造一次空指针异常：调用 `findById(999)` 之后直接对返回值调用 `.getName()`，看它崩在哪一行。

## 验收标准

- [ ] `javac` 零报错，`java App` 有完整输出
- [ ] 删除后再次查询该 id 确实查不到
- [ ] 空指针异常信息能指到具体行号，并说出"为什么是这一行"

## 提示（先自己试，卡住再看）

- Java 字符串只能用英文双引号 `"..."`，单引号 `'A'` 只装单个字符。
- 每条语句结尾是英文分号 `;`，报 `非法字符: '\uff1b'` 就是写成了中文分号。
- `List` 的 `remove(int index)` 和 `remove(Object o)` 是两个重载；想按 id 删，先找到对象再删。
- 判断两个字符串内容是否相等用 `equals`，不用 `==`。
- 空指针只说明"这个变量是 null"，不说明谁把它变成了 null —— 往上找一处就能定位。
