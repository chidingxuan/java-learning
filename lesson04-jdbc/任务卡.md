## 1. 第一个程序：DbDemo.java

目标：连上 `../lesson03-sql-basics/shop.db`，查出 `level >= 1` 的客户，打印 id / name / phone / level。

必须用到的四件套：

| 类 | 作用 |
|---|---|
| `DriverManager.getConnection(url)` | 拿到连接 |
| `PreparedStatement` + `?` | 带参数的 SQL，参数用 `ps.setInt(1, 1)` 填 |
| `ResultSet` | 查询结果，用 `while (rs.next())` 逐行读 |
| `try (...)` | try-with-resources，自动关连接，别手写 close |

连接串：

```java
String url = "jdbc:sqlite:/Users/chidingxuan/Desktop/kimi/kimi学习/lesson03-sql-basics/shop.db";
```

**预期输出**（我实测过）：

```
1 小明 13800001111 1
2 小红 13900000222 2
```

## 2. 第二步：把查询包成方法

```java
static Customer findByID(int id) throws SQLException
```

- 里面用 `SELECT ... WHERE id = ?`
- `rs.next()` 为 false 就 `return null`，否则读出字段 `new Customer(...)` 返回
- 在 main 里调用 `findByID(999)`，验证返回 null 而不是崩溃

注意：`Customer` 类从 lesson02 复制过来，字段和构造方法不用改。

## 3. 第三步：SQL 注入（实习第一周就会被问）

先写两个版本做对比：

```java
// 危险版：字符串拼接
String sql = "SELECT * FROM customer WHERE name = '" + input + "'";

// 安全版：占位符
String sql = "SELECT * FROM customer WHERE name = ?";
```

输入这个字符串试试：

```
' OR '1'='1
```

- 拼接版会返回**所有客户**—— 因为 SQL 变成了 `WHERE name = '' OR '1'='1'`，条件恒真
- 占位符版返回 0 行，因为它把整串当成普通字符串去匹配名字
