## 1. 建两张表（自己敲，别复制）

**customer**：`id INTEGER PRIMARY KEY`、`name TEXT NOT NULL`、`phone TEXT`、`level INTEGER DEFAULT 0`

**orders**：`id INTEGER PRIMARY KEY`、`customer_id INTEGER NOT NULL`、`amount REAL NOT NULL`、`created_at TEXT NOT NULL`

> `orders` 是 SQL 关键字，用它可以，但更稳妥的写法是加反引号或改名 `orders` → 建表时若报 syntax error，改成 `"orders"`。

## 2. 插数据

- 3 个客户
- 5 个订单
- **其中至少有一个客户一单都没下** —— 第 6 题要用

## 3. 六道查询（每道都要自己写出来）

1. 查所有客户
2. 查 `level >= 1` 的客户，按 `id` 降序
3. 查金额大于 100 的订单，按金额降序
4. 把 `id = 1` 的客户电话改成 `13800001111`
5. 查每个客户各有几单（提示：`GROUP BY` + `COUNT`）
6. 查**没有下过订单的客户**（提示：`LEFT JOIN` 之后 `WHERE o.id IS NULL`）

## sqlite 与 MySQL/Oracle 的差异（面试和实习都会被问）

| 点 | sqlite | MySQL |
|---|---|---|
| 主键自增 | `INTEGER PRIMARY KEY` 自动 | `INT PRIMARY KEY AUTO_INCREMENT` |
| 类型检查 | 宽松，可以往 INTEGER 列塞字符串 | 严格模式直接报错 |
| 日期 | 存成 TEXT | 有 `DATETIME` / `DATE` 类型 |
| 分页 | `LIMIT n OFFSET m` | 同左（Oracle 12c 前用 `ROWNUM`） |
| 字符串拼接 | `\|\|` | `CONCAT()` |
